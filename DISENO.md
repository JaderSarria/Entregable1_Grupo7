# Interfaz sencilla

Pantalla de administración sin marca, logotipos, ilustraciones ni mensajes decorativos.

- Fondo gris claro, contenido blanco, texto oscuro y botones verde oliva.
- Tipografía del sistema y títulos de tamaño normal.
- Navegación con dos pestañas: Mascotas y Usuarios.
- Fichas con fotografía grande, bordes suaves y bloques de edad, sexo y color para mascotas; tabla para usuarios.
- Búsqueda, formularios, edición, detalle y confirmación de borrado.
- Diseño adaptable a pantallas pequeñas, sin dependencias externas.

La funcionalidad y la API se conservan. Las pruebas automatizadas verifican la API y los archivos estáticos; la revisión visual en navegador sigue pendiente por restricciones del entorno.
